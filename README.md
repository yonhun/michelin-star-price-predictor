# 🍽️ 미슐랭 레스토랑 가격대 및 스타 등급 예측 프로젝트
**2024 머신러닝입문 1팀 프로젝트**

본 프로젝트는 미슐랭 가이드 데이터를 바탕으로 레스토랑의 **가격대(Price Range)**와 **미슐랭 스타 등급(Stars)**을 예측하는 머신러닝 모델을 구축하고 분석한 프로젝트입니다.

## 1. 프로젝트 개요
* **배경:** 최근 미식에 대한 대중적 관심이 높아짐에 따라, 데이터 기반으로 레스토랑의 가치 평가와 등급 산정의 특징을 분석하고자 기획되었습니다.
* **목적:** * 요리 유형, 지역 등의 특성을 활용한 가격대(Price) 예측 모델 구축.
    * 미슐랭 스타 등급(1~3성) 결정 요인 분석 및 예측 성능 확인.
    * 실제 레스토랑 사례(예: 모수 서울)를 통한 모델 검증 및 공정성 탐색.

## 2. 주요 기능 및 분석 내용
* **데이터 전처리:** 미슐랭 1, 2, 3스타 데이터를 통합 정제하고 범주형 데이터(Cuisine, Region 등) 인코딩 수행.
* **데이터 시각화:** 스타 등급별 분포 및 지역별 위치 기반 시각화(Folium 활용).
* **모델링 및 학습:** RandomForest, XGBoost, Decision Tree 등 다양한 알고리즘을 비교 분석하여 최적의 예측 모델 도출.
* **예측 시스템:** 특정 레스토랑의 정보를 입력받아 예상 스타 등급과 가격대를 출력하는 예측 함수 구현.

## 3. 기술 스택 (Tech Stack)
* **언어:** Python
* **라이브러리:** Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Folium
* **환경:** Jupyter Notebook, Kaggle Kernel

## 4. 데이터셋 정보
* **출처:** Kaggle Michelin Guide Restaurants Dataset
* **주요 변수:** 연도(Year), 위치(Latitude/Longitude), 도시/지역(City/Region), 요리 유형(Cuisine), 가격(Price), 스타 등급(Stars)

## 5. 실행 방법
1. 이 레포지토리를 클론(Clone)합니다.
2. `[머신러닝입문] 1팀 프로젝트 소스코드.ipynb` 파일을 실행합니다.
3. 소스코드 내 `predict_category` 함수를 사용하여 새로운 레스토랑의 데이터를 테스트할 수 있습니다.
